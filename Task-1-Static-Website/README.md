# Task 1: Deploy a Static Website on Google Cloud Storage

## Objective
Deploy a simple static website using Google Cloud Storage and make it publicly accessible through a web URL.

## Cloud Platform
Google Cloud Platform (GCP)

## Technologies Used
- Google Cloud Storage
- HTML
- CSS
- JavaScript

## Implementation
1. Created a Google Cloud Storage bucket.
2. Configured the bucket for public access.
3. Created and uploaded the `index.html` file.
4. Granted public read access using the Storage Object Viewer role.
5. Accessed the deployed website through its public Google Cloud Storage URL.
6. Tested the JavaScript functionality using the Test Website button.

## Live Website
https://storage.googleapis.com/internspark-cloud-haseeb-2026/index.html

## Result
The static website was successfully deployed on Google Cloud Storage and is publicly accessible through the internet.
